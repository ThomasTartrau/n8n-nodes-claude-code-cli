# Security policy

## Supported versions

Only the latest release on npm receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through GitHub:
https://github.com/ThomasTartrau/n8n-nodes-claude-code-cli/security/advisories/new

Security maintainer: Thomas Tartrau ([@ThomasTartrau](https://github.com/ThomasTartrau))

I aim to acknowledge reports within 72 hours and to publish a fix and a GitHub Security Advisory once the issue is resolved. Reporters are credited in the advisory unless they ask otherwise.
